# game-assets (MajorasPride)

Free CC0 assets shared by all MajorasPride games and tools (Mythic Forge, Titan Clash, Shoebox Studio and more).

- assets-fx-sound-ui-sky.zip: Kenney particles, UI pack and 5 sound packs; 3 Poly Haven night-city skies (2K .hdr)
- assets-textures.zip: ambientCG Concrete034, Metal032, MetalPlates006, PaintedMetal017, Rock030 (2K color, normal, roughness, metalness)

All CC0 (see LICENSES.md). Cloud builds can download them from
https://raw.githubusercontent.com/MajorasPride/game-assets/main/<file>.zip
Copy only what a project uses into that project's repo.
