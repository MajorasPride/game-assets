## For cloud builds (Opus/Fable runs that can't see this PC)
- ToxSam models can be fetched straight from GitHub: https://raw.githubusercontent.com/ToxSam/cc0-models-Polygonal-Mind/main/projects/<folder>/<file>.glb (thumbnails: same path with _thumbnail.png). Full list: toxsam-cc0/urls.txt.
- Everything else here (Kenney, Poly Haven, ambientCG, Quaternius) lives only on this PC. A cloud build that needs one should copy just the files it uses into the project repo (or ask for a PC chat).
- toxsam-cc0/get.sh re-downloads any missing ToxSam models (safe to re-run).
